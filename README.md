# 🐙 Capacitación Git — Equipo de Soporte

Bienvenidos al repo de práctica para la capacitación de Git.

## 📋 ¿Qué vamos a hacer hoy?

- ⚙️ Configurar Git en nuestra compu
- 📥 Clonar este repositorio
- ✅ Hacer nuestro primer commit
- 🔄 Subir y bajar cambios con el equipo

## 🖐️ Presentate!

Abrí el archivo `presentaciones.txt`, agregá tu nombre y hacé tu primer commit.

## 📌 Comandos del día

| Comando | ¿Qué hace? |
|---|---|
| `git clone URL` | Baja el repo a tu compu |
| `git status` | Ver qué archivos cambiaron |
| `git add .` | Preparar los cambios |
| `git commit -m "mensaje"` | Guardar una foto del proyecto |
| `git push` | Subir los cambios al servidor |
| `git pull` | Bajar los cambios del equipo |
