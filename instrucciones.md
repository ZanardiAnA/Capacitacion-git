# Instrucciones para la práctica

## 1. Clonar el repo
git clone https://github.com/ZanardiAnA/Capacitacion-git.git

## 2. Entrar a la carpeta
cd Capacitacion-git

## 3. Agregar tu nombre
echo "Tu nombre" >> presentaciones.txt

## 4. Ver el estado
git status

## 5. Preparar el cambio
git add presentaciones.txt

## 6. Hacer el commit
git commit -m "Me presento: Tu nombre"

## 7. Subir los cambios
git push
