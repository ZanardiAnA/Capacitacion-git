Comando      ¿Qué hace? 
git clone    Bajás el repo a tu compu
git status   Ves qué archivos cambiaron
git add      Preparás los cambios para guardar
git commit   Sacás una foto del proyecto
git push     Subís los cambios al servidor
git pull     Bajás los cambios del equipo
git log      Ves el historial de todo lo que pasó
