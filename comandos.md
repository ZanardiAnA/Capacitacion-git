# Comandos de hoy

| Comando | ¿Qué hace? |
|---|---|
| `git clone` | Bajás el repo a tu compu |
| `git status` | Ves qué archivos cambiaron |
| `git add` | Preparás los cambios para guardar |
| `git commit` | Sacás una foto del proyecto |
| `git push` | Subís los cambios al servidor |
| `git pull` | Bajás los cambios del equipo |
| `git log` | Ves el historial de todo lo que pasó |

# Para explorar después

| Comando | ¿Qué hace? |
|---|---|
| `git branch` | Ves o creás ramas de trabajo |
| `git checkout` | Cambiás de rama |
| `git merge` | Unís los cambios de dos ramas |
| `git diff` | Ves exactamente qué líneas cambiaron |
| `git stash` | Guardás cambios temporales sin commitear |
| `git reset` | Deshacés cambios |
